# 实验二演示视频脚本

建议时长 2～3 分钟，保持一次连续录制。

## 1. 启动与主界面（约 15 秒）

1. 启动 `SimpleTextEditor.exe`。
2. 展示“文件、编辑、格式、查看、帮助”菜单，以及按功能分组的工具栏。
3. 在编辑区输入多行中文，展示行号、当前行高亮和底部字符数、行列位置。

## 2. 文件新建、打开和保存（约 40 秒）

1. 新建文档，输入两行内容，窗口标题出现 `*`。
2. 选择“保存”，在对话框输入文件名，保存后标题中的 `*` 消失。
3. 修改内容后选择“打开”其他文本文件，展示未保存提示。
4. 选择“取消”，确认当前文档仍在；再次打开，选择“保存”后继续。
5. 打开已准备的中文 UTF-8 文本并在编辑区显示。

## 3. 查找与替换（约 35 秒）

1. 使用 `Ctrl+F` 打开查找对话框。
2. 查找一个出现多次的词，连续点击“查找下一个”，展示环绕查找。
3. 勾选“区分大小写”，查找大小写不匹配的内容，展示“未找到”。
4. 使用 `Ctrl+H` 打开替换对话框，演示替换当前项。
5. 演示“全部替换”的数量提示，并只按一次撤销恢复整批内容。

## 4. 编辑动作与格式（约 35 秒）

1. 选中一段文字，展示剪切、复制按钮由不可用变为可用。
2. 执行复制、粘贴、撤销和重做。
3. 修改字体、字体颜色和字体背景色。
4. 修改编辑器背景色，再切换自动换行和显示行号。
5. 在“查看”菜单隐藏、恢复工具栏和状态栏。

## 5. 异常与边界场景（约 25 秒）

1. 尝试打开不存在的文件，展示错误提示。
2. 尝试打开包含二进制内容的文件，展示拒绝提示，确认原编辑内容未被替换。
3. 修改已保存文档后关闭窗口，展示“保存/放弃/取消”提示。

## 6. 关于与 Git 历史（约 20 秒）

1. 打开“帮助 → 关于”，展示开发者刘泽、学号和邮箱。
2. 切换到终端或 Git 客户端，展示本次实验二相关提交历史。
3. 结束录制。
