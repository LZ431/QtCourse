# 2～3分钟演示视频脚本

录制前先显示命令行中的 `git log --oneline -8`，然后打开 `KeyboardCalculator.exe`。建议全屏录制，分辨率至少 1280×720，鼠标点击与键盘按键都要出现在画面中。

## 0:00～0:15 开场

1. 展示程序窗口和项目名称。
2. 说明：“本视频演示实验一计算器的鼠标、键盘、连续运算和异常输入处理。”

## 0:15～0:45 鼠标小数运算

1. 鼠标依次点击 `1`、`2`、`.`、`5`、`×`、`2`、`.`、`4`、`=`。
2. 展示表达式 `12.5 × 2.4 =` 和结果 `30`。

## 0:45～1:05 键盘运算

1. 按 `Esc` 清除。
2. 键盘输入 `845+996`，展示表达式区域的输入过程。
3. 按 `Enter`，展示结果 `1841`。

## 1:05～1:20 退格与清除

1. 按 `Esc`。
2. 键盘输入 `12345`，连续按两次 `Backspace`，展示当前值变为 `123`。
3. 按 `C`，展示结果恢复为 `0`。

## 1:20～1:40 除零处理

1. 键盘输入 `9/0`。
2. 按 `Enter`，展示“错误”。
3. 按数字 `7`，展示程序从错误状态恢复。

## 1:40～2:05 连续运算与等号后继续输入

1. 输入 `6+3*2=`，展示结果 `18`。
2. 继续按 `*2=`，展示从结果继续运算得到 `36`。
3. 按 `C`，输入 `2+3=`，再直接输入 `8`，说明等号后数字会开始新计算。

## 2:05～2:25 异常输入和混合输入

1. 输入 `12.3.4+8+*2=`，说明重复小数点和连续运算符被过滤/替换，展示最终结果。
2. 清除后用键盘输入 `12.5+2=`，再用鼠标点击 `×`，最后用键盘输入 `2=`，展示得到 `29`。

## 2:25～2:50 Git历史

1. 打开终端，在仓库根目录运行：

   ```powershell
   git log --oneline --decorate -8
   ```

2. 展示至少 5 个与实验一相关的提交，重点指出键盘事件、测试和问题修复提交。
3. 结束视频。
